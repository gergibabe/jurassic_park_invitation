# Jurassic Dark Invitation

A self-contained GitHub Pages invitation animation.

## Files

- `index.html` — page markup
- `style.css` — 3D postcard/VHS animation and responsive styling
- `script.js` — open/replay interaction
- `assets/postcard.png` — postcard with the original white background removed
- `assets/vhs.jpg` — VHS invitation image

## Run locally

Open `index.html` in a browser, or serve the folder with any simple local web server.

## Publish on GitHub Pages

1. Upload the contents of this folder to your repository.
2. In GitHub, open **Settings → Pages**.
3. Select **Deploy from a branch**.
4. Choose the branch containing these files and the `/ (root)` folder.
5. Save and open the generated Pages URL.

The site has no external libraries or build step, so it can be hosted directly from the repository.
